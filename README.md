

# ⚡ FreeStack

**منصة مجتمعية لأدوات ذكاء اصطناعي وتطوير مجانية**





## عن المشروع

FreeStack هي منصة ويب مجتمعية تجمع الأدوات والتطبيقات المجانية التي تساعد المطورين والمصممين العرب في كل مكان

الفكرة بدأت من مشكلة بسيطة: كل يوم بنكتشف أدوات AI جديدة ومننساهن بعد يومين. فقررت أبني "مكتبتي الشخصية" وأشاركها مع العالم.

**الأجمل؟** المشروع بالكامل مبني من هاتف Android باستخدام Termux و GitHub Codespaces!

##  المميزات

- 🔍 **بحث وفلترة** حسب التصنيف
- ⭐ **تقييم مجتمعي** بدون تسجيل دخول
- 📝 **اقتراح أدوات** جديدة 
- 🛡️ **لوحة مشرف** لإدارة الاقتراحات
- 📱 **التصميم متجاوب** للهاتف والكمبيوتر

## 🛠️ التقنيات المستخدمة 

`Next.js 16` · `TypeScript` · `Tailwind CSS` · `Supabase` · `Vercel`


## 🚀 الرابط

**https://freestack-vuse.vercel.app**

## 💻 التشغيل محلياً

```bash
# 1. استنساخ المستودع
git clone https://github.com/Abdomghrbi/Freestack.git

# 2. الدخول للمجلد
cd freestack

# 3. تثبيت الحزم
npm install

# 4. إعداد متغيرات البيئة
# أنشئ ملف .env.local وأضف:
# NEXT_PUBLIC_SUPABASE_URL=your_url
# NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key

# 5. تشغيل الخادم التطويري
npm run dev
